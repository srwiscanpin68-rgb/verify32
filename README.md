# Roblox Verification Discord Bot

บอท Discord สำหรับระบบยืนยันตัวตน (Verification) ที่เชื่อมโยงกับข้อมูล Roblox พร้อมระบบแอดมินตรวจสอบ

## 📌 คุณสมบัติ
- **ปุ่มยืนยันตัวตน**: แสดง Embed พร้อมรูปภาพและปุ่มกด
- **ระบบคำถาม**: ถามชื่อ Roblox และคำถามอื่นๆ (กรม, หน่วย, สถานะกบฏ)
- **ระบบแอดมิน**: ส่งข้อมูลไปยังช่องลับเพื่อให้แอดมินกด "รับ" (ให้ยศ) หรือ "ไม่รับ" (เตะออก)
- **ความปลอดภัย**: เฉพาะแอดมินที่มี ID ตรงกับที่ตั้งค่าไว้เท่านั้นที่สามารถกดปุ่มอนุมัติได้

## 🛠 วิธีการติดตั้ง

1. **เตรียมบอทใน Discord Developer Portal**:
   - สร้าง Application ใหม่ที่ [Discord Developer Portal](https://discord.com/developers/applications)
   - ไปที่เมนู **Bot** แล้วเปิดใช้งาน **Message Content Intent** และ **Server Members Intent**
   - คัดลอก **Token** ของบอทมาไว้

2. **แก้ไขไฟล์ `bot.py`**:
   เปิดไฟล์ `bot.py` และแก้ไขค่าดังนี้:
   - `TOKEN`: ใส่ Token ของบอทคุณ
   - `ADMIN_USER_ID`: ใส่ ID ของคุณ (หรือคนที่จะเป็นแอดมิน)
   - `LOG_CHANNEL_ID`: ID ของช่องลับ (`1529416449267859567`)
   - `VERIFIED_ROLE_ID`: ID ของยศที่จะให้ (`1465361475035201762`)
   - `IMAGE_URL`: ลิงก์รูปภาพที่ต้องการให้แสดงใน Embed

3. **ติดตั้ง Library ที่จำเป็น**:
   ```bash
   pip install discord.py
   ```

4. **รันบอท**:
   ```bash
   python bot.py
   ```

## 🚀 วิธีใช้งานใน Discord
1. พิมพ์คำสั่ง `!setup_verify` ในช่องที่ต้องการให้มีปุ่มยืนยันตัวตน (ต้องเป็นแอดมินเท่านั้น)
2. เมื่อสมาชิกกดปุ่ม "ยืนยันตัวตน" บอทจะถามความพร้อม
3. เมื่อตอบคำถามครบ ข้อมูลจะถูกส่งไปที่ช่องลับ
4. แอดมินกดปุ่ม **รับ** เพื่อให้ยศ หรือ **ไม่รับ** เพื่อเตะออกจากเซิร์ฟเวอร์
